# Помощник учителя на основе YOLO

Программа находит учеников на видео с камеры, считает признаки поведения и подсказывает учителю,
на кого стоит обратить внимание. Она ничего не диагностирует: решение всегда принимает человек.

## Установка и запуск
    pip install -r requirements.txt
    python detector.py --source 0          # камера
    python detector.py --source video.mp4  # видеофайл
При первом запуске модель `yolov8n-pose.pt` скачивается автоматически (нужен интернет один раз).
Выход: клавиша `q`.

## Какие сигналы ищет программа
| Сигнал | Как определяется |
|---|---|
| много двигается или ходит по классу | путь центра фигуры за окно наблюдения, делённый на рост фигуры |
| долго не смотрит вперёд | нос не виден или почти на уровне плеч большую часть окна наблюдения |
| долго держится в стороне | расстояние до ближайшего ученика больше порога почти всё окно |
| резкие движения рядом с другим | быстрые движения запястий при малом расстоянии до другого ученика |

Пороги задаются в начале класса `ClassroomWatcher` и подбираются под конкретную камеру и класс.

## Защита данных
- лица не распознаются, ученик отображается только номером (ID) в кадре;
- видео и кадры не сохраняются, в журнал `signals_log.csv` пишутся время, номер и тип сигнала;
- вся обработка идёт на вашем компьютере, без отправки данных в интернет;
- использовать только с согласия родителей и в соответствии с законом № 152-ФЗ.
